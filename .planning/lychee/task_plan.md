# 荔枝当前计划

## 荔枝 7.0 更新

2026-11-26 负责人确认本轮范围，从 6.4.7 接手。以下记录本轮验收条件。

### 1. 多端消息提醒

- [ ] 手机网页已升至 7.0.2，沿用已启用的生产后台推送。负责人用 iPhone 从主屏幕进入「通知中心」开启后台通知，分别验证退回桌面和锁屏时收信、点通知直达对应聊天。

- [ ] 盘点会产生个人提醒的事件，覆盖聊天新消息、「问一问」回复、到期提醒和其他与本人有关的板块动态。点击提醒直达对应内容，同一设备上的同一事件只提醒一次。
- [ ] Windows 切到其他软件或最小化时，收到消息要弹窗、响铃、任务栏闪烁。点「×」即退出，停止提醒，再打开能看到期间收到的未读消息。
- [ ] 先用两个测试账号复现 6.4.7 漏提醒，再按相同场景复测。Android APK、手机浏览器、iPhone 主屏幕网页版分别检查前台、后台、锁屏及关闭页面后的送达和点击结果，按实际设备记录通过项和缺口。

### 2. 照记饮食

- [ ] 手机支持拍照、相册选图，Windows 支持选图。参考 nosh 的按日手帐：实拍食物抠成贴纸，标菜名和单项热量，页头显示当天合计，可切换日期回看。
- [ ] 点贴纸查看热量、蛋白质、碳水和脂肪。支持修正食物、单项份量和实际吃下的比例，保存后同步重算单项和当天合计。
- [ ] 后台由视觉 AI 识别食物和份量，按营养条目计算。包装食品优先读本品标签。拟以[台湾食药署中文库](https://data.gov.tw/dataset/8543)为主、[美国农业部数据库](https://fdc.nal.usda.gov/download-datasets/)补缺。匹配生熟状态、可食份量和烹饪方式，组合餐避免重复计油。按常吃中餐的实际缺口补配方；大陆疾控平台用于抽查，薄荷接口为备选。
- [ ] 先用带标签的包装食品、称重单品、已知原料和用油的家常盖饭做对照。同一批照片比较纯 AI 与查库方案，记录每餐热量和三大营养素与参考值的差异、需要手改的项目，并验证改份量后的合计。
- [ ] 实拍验收仍缺包装标签与大陆家常菜。已授权的 8 次公开称重餐照调用已用尽，结果和复算入口见[进展](progress.md)；继续比较时计入需人工补录的餐，按餐记录热量和三大营养素差异。新增付费调用需另获授权。

### 3. 自定义转盘「交给命运」

- [ ] 用吃饭和其他主题分别测试：增删后分区和文字同步，点「转一下」后转动、减速、随机停止，显示结果与指针所指选项一致。
