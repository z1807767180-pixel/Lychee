# 荔枝关键发现

各端现有验证边界见[项目交接](../../docs/项目交接.md)。这里记录会影响后续工作的关键发现及依据，也记录遇到的缺陷、查实的原因、有效修法和验证结果，方便下次少走弯路；仍在排查或尚未修复的照实标明。

- 旧「我的约定」按园内成员编号查询，各园可出现相同编号。新版统一首页若展示旧约定，应通过原园与该成员编号对应的稳定账号绑定确定本人；旧园沿既有映射，缺失或冲突的记录留在原处。现有树也是每园一棵，其生长、采摘、赠果记录涉及多人。新版个人树不能把旧群树历史自动算给某位成员。[旧个人约定](../../source/legacy/v61.mjs) · [成员身份与分园数据](../../source/server/turso-domains.mjs) · [旧树与赠果](../../source/legacy/yard65.mjs)
- 现有切圈会重新导航，启动页随新文档出现；列表只有当前圈读取自设封面，其他圈使用默认图。自设图按设备上的账号与园保存。新要求的固定群封面与切群无启动页都须从实际群列表验证。[切圈和卡片](../../source/client/garden.js) · [本机保存范围](../../source/client/business-scope.js)
- 老安卓白屏有两个可独立复现的条件。Android 9 / WebView 69 无法解析旧发布包的部分现代 JavaScript，另在只有不可见表单时，旧启动层会过早撤下。网页脚本按 Chrome 69 编译并补齐运行时接口，启动层等实际可见控件绘制后再撤。签名安卓候选在 WebView 69 和 124 均完成登录、发消息和五题；原录像不足以确定该设备是哪一种原因。[启动绘制回归](../../source/test/mobile-startup-paint.mjs) · [兼容构建](../../source/mobile-web/legacy_webview.py)
- 手机网页转盘的旧横幅下载失败后会变成空的黄色方块，轮轴也会消失，两幅图已随转盘资源内置。以 WebKit 和真实安卓 WebView 验得横幅为 642×147、轮轴 82×82，可正常转动。用户现场为什么没拿到图片仍待反馈。[转盘资料](../../source/mobile-web/wheel_art.py) · [WebKit 回归](../../source/test/mobile-wheel-webkit.mjs)
- 旧工具即使由个人首页打开，启动时也读取当前成员名册。个人工具只开放本人账号专属位置的固定只读名册查询，同时停掉在个人工具内无意义的群未读轮询。不要把个人工具位置当作真实群成员关系。[服务端权限回归](../../source/test/social-routes.test.mjs)

- 负责人所说的「找题库」指从已有题库选题；题面、干扰项和提示可以为荔枝整理，每道要能回到其原题。几个标签可同时用于一道海龟汤，统计净增量时按题目 ID 去重。正式来源与许可见[第三方说明](../../source/third-party/README.md)。

- 圈子人数取自本园的成员关系；`mc_members` 对同一账号和园设唯一约束。新园创建者登记为 `owner`，邀请加入者登记为 `member`；原始园迁移可保留多位或没有已登记的圈主。应按现有角色展示，不能凭座位号、在线人数或聊天记录推断。见[账号工程](../../source/server/accounts.mjs)和[历史迁移](../../source/server/turso-migrate.mjs)。

- 安卓 6.4.7 的页面、字体和脚本随 APK 内置，后台接口才走网络。单独重打包只会带上当时的网页。后续交付要分别处理官方网页内容更新和安卓安装包升级；从朋友首装版起，安装包覆盖升级依赖该版的包名和正式签名。工程入口见[安卓工程说明](../../source/android/README.md)。

- 移动网页主园与历史频道均按北京时间零点清除聊天。日期分组沿用这条规则。旧图片只有原图，靠按需加载和复用避免重复传输。新版手机网页发送的较大照片可附带小预览，服务端沿用原图片的访问、撤回和过期检查。网页发布与验证范围见[阶段归档](阶段归档/2026-11.md)。

- 照记饮食：整餐份量问题已修并在 Windows 实际保存复验。修复前对照见[阶段归档](阶段归档/2026-11.md)。评估识别质量时，仍须把无法算全的餐计入总样本；真实识图、同批离线重放的数值及限制见[阶段归档](阶段归档/2026-11.md)。
