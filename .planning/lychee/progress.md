# 荔枝当前进展

**手机网页界面发布与手机试用。** V8.0.2 已在原网址单独上线，核对了构建、实际入口、版本和指定脚本。各阶段源代码经 Router 对照，真实手机上的外观、操作和通知由负责人试用。已有 Windows 与安卓朋友壳升级反馈继续保留。[正式回执](../../distribution/mobile-web/verified-8.0.2.json)

- 荔圈首页可按本人选择展示约定，右上角「＋」统一建群、加群。共同计划按本人已加入的群汇总。通过原数据与权限代码核对。
- 园中事、问一问、约定使用可区分的主题内页。小园返修为整幅园景，园内交互含水壶和树冠采果。SQLite 与 libSQL 隔离夹具覆盖原库存、好友操作与重复采收。
- 工具箱各项直达当前客户端组件。好友私聊受邀方接受才开始游戏，旧群对局仍按原群权限与原对局编号打开。隔离检查覆盖无共群好友、等待与旁观权限。
- 「我」的头像与主题、昵称与登录账号、个签、趣味状态、实际版本、检查更新、退出登录、公告已读和通知入口已做代码核对。
