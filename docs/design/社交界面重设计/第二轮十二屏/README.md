图中使用虚构账号青禾及其好友。群聊暂用清爽款演示，首轮的[两种群聊风格](../猪圈群聊-双方案对照.png)仍可对照。各板块用相关场景说明操作，数字随对应场景改变。

- **荔圈。** 首页保留个人约定卡，以及群聊、私聊混排的一份会话列表。猪圈内头像、昵称和分段时间同屏可读，长按自己的消息可看到操作示例。
- **荔枝园。** 首页只有园中事、问一问、约定、荔枝树四个入口。好友动态和评论放在园中事，问题列表、发问和回答放在问一问。
- **约定。** 「我的计划」放自己的安排，「共同计划」呈现多人参与的安排。图 08 的参与人选择和确认是建议方案，示例不决定创建权、编辑权、邀请机制或历史共同约定的归属。
- **小院。** 青禾的树有 6 颗成熟果，果篮原有 2 颗。采下后有 8 颗，去阿青家送出 1 颗，自己的果篮剩 7 颗。赠送回执和留言显示院主与访客。
- **工具箱和我。** 工具箱按日常、一起玩、AI 排列 11 个直接入口；好友从「我」进入。约定卡从首页可直接打开，约定、问一问和荔枝树归入荔枝园。

本轮交付为设计参考。后续还原按项目记录，用同一台老安卓与 8.x 对照启动、进群、长会话滚动、切群、输入和后台恢复，实测内存、绘制与网络请求。样稿里的数字展示信息关系，通知送达、已读时机和真机运行速度要在实际软件中核验。
