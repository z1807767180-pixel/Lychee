## 老安卓还原验收

后续开发复用消息行和头像，按显示尺寸提供小院插画，控制正文背景层次。在同一台老安卓、相同数据量与网络条件下，对照 8.x 的冷启动、进群、长会话滚动、切群、输入及后台返回，实测等待、掉帧、内存和网络请求。正式通知到达/消除时机另在实际设备上核验。
