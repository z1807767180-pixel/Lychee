## 主题素材和已有设置

默认款取正式小院、荔枝吉祥物为视觉参考，用 ImageGen 新绘竖幅。凯蒂、米菲和图图使用仓库已有的 `hd-wall-3/1/2.webp` 竖图与相应的 `hd-theme-3/1/2.webp` 果园远景组合。群聊的五条消息和发言人头像均相同。荔枝园各款共用相同的入口图案，园中事和问一问各 1 条未读。

主题命名和初值见[旧手机版主题定义](../../../../source/source/web/mobile/phone.js#L118)，Windows 也有[同组定义](../../../../source/source/web/windows/phone.js#L118)。默认选用「原味荔枝园」。旧界面的[聊天背景取值](../../../../source/source/web/mobile/phone.js#L410)会优先使用在本机选过的个人壁纸。图中演示使用主题自带壁纸的情形，还原时应保留已有人的选择。四款图在本页的展示顺序不改变程序原来的主题编号。

## 导出和后续实测

八张单屏为 788 × 1692 像素。四个群聊在 394 × 846 与 320 × 700 的浏览器布局均已检查，五条消息和输入区无重叠。群聊每款共用一张 660 × 1417 的 WebP 背景，本轮文件在 45,802 至 164,824 字节之间。正式开发后按[老安卓还原验收](../README.md#老安卓还原验收)测量内存、绘制、请求和前后台行为。
