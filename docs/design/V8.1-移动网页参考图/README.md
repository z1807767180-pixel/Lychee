# 荔枝 8.1 移动网页参考图

移动网页版 V8.1.0 的已批准还原基准。打开[56 页逐屏画册](荔枝8.1-手机逐屏画册.pdf)可在手机上按页翻看，书签可以跳到指定页面。看同屏对比可打开[分组预览](分组预览/)。56 张高清单屏由荔枝园 12 张、工具 11 张、个人与主题 33 张组成，均为 780 × 1688 像素。问一问按页面身份替换原好友问题列表，沿用「今晚吃什么？」和「问问大家」入口；零提问首页展示同一入口。有回答的问题详情保留。

原味荔枝园的园中事首屏采用暖纸底色、紧邻计数的表情按钮和内嵌评论；问一问用问题卡及独立回答段落。两页取同一主题，可以直接比较用途。动态作者、提问人、评论、数字、照片和联系人全部为示例。小量评论直接显示，更多评论可展开。群聊置顶以已审稿实施，群主按现有群权限管理。资料按既有可见关系展示。

园中事的示例果照由内置 ImageGen 生成。提示内容为横幅手机随拍，竹盘内放刚摘的红荔枝与一颗剥开的果实，窗边自然光，无人物、文字和界面；生成图缩存于[示例果照](荔枝园/示例果照.jpg)。头像、园中事导航图标、问一问图标和荔枝时钟等来自项目既有素材。

这份 56 页画册是经负责人批准的视觉基准。8.1.3 群聊、私聊采用四主题构图、单行输入栏及三个加号入口，保留旧版表情分类和荔枝贴纸。运行效果见[四主题和两个面板](../../../distribution/mobile-web/chat-8.1.3/)，各端发布、设备实测和待验边界见[项目交接](../../项目交接.md)。
