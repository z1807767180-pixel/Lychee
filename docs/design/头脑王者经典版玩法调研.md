# 《头脑王者》经典微信版玩法调研

2026-11-27。供荔枝「工具箱 → 一起玩」讨论玩法时参考。主要观察对象是 2018 年 1 月的微信版，另用 2017 年实玩资料比较版本变化。下文的界面和比分来自当年截图，本轮未运行原版客户端。

## 一局怎样进行

好友对战由一人发起，另一人点微信邀请进入。房间顶部显示双方头像，缺人时对手位留空。人齐后发起者点「开始对战」。排位赛则从已开放的段位场进入，系统匹配对手，有金币入场费。两人各自在手机上回答相同的五道四选一，每题限时 10 秒，点选锁定；双方都选好就能揭晓，正确项变绿。五题分开计时，纯作答时间上限为 50 秒，另计匹配、转场、揭晓和结算。[好友从邀请到结算](https://jingyan.baidu.com/article/e4d08ffd614d3b0fd2f60d97.html) · [排位全流程截图](https://jingyan.baidu.com/article/bad08e1ed7e4d209c9512161.html) · [玩家对四选一的记录](https://www.sohu.com/a/200189445_278248)

## 时间、计分和胜负

基础规则按五题累计分判胜，高分获胜。普通题答错 0 分，答对时首个计时档 200 分，倒计时剩 9 秒为 180 分、剩 8 秒为 160 分，每慢一档少 20 分。末题画面标明「双倍积分 ×2」，基础最高 400 分。按四道普通题各 200 分加末题 400 分，基础理论满分为 1200 分。特定领域的知识升级可以影响得分，结算中的金币、经验与比赛分各有独立显示。[玩家计分记录](https://www.sohu.com/a/200189445_278248) · [同期机制报道](https://cn.technode.com/post/2018-01-26/tounaowangzhe-2/) · [胜负规则](https://www.nbd.com.cn/articles/2018-01-31/1189091.html)

截图中有一局，末题刚开始时左方 360、右方 400，结算是左方 560、右方 400，左方获得「绝杀」。这两帧可验证末题双方得分差和总分判胜；画面未记录左方按下答案的时刻。[末题与结算两帧](https://jingyan.baidu.com/article/bad08e1ed7e4d209c9512161.html)

尚待原始证据的细节有三项。其一，完全同分时的胜负和星数处理。其二，末题逐秒分档：同期攻略一面称“双倍”，一面列出 400、380、360；若逐档乘二则为 400、360、320。其三，倒计时归零一刻的提交边界、超时和中途退出的具体结算。最长连续答对数出现在结算页，未找到用它裁决同分的证据。[含逐秒举例的同期攻略](https://m.ali213.net/news/gl1801/211785.html) · [结算截图](https://developer.cloud.tencent.com/article/1167924)

## 段位如何升

经典排位共 14 段。排位胜一局通常加一星、负一局减一星，积满本段星数可进下一段。最高段继续累计王者星数。角色 Lv.、经验、金币、段位及本局得分分别显示。好友房截图中金币和经验均为 +0，不能由此推断所有版本和模式的道具奖励。[排位机制实访](https://cn.technode.com/post/2018-01-26/tounaowangzhe-2/) · [王者段位采访](https://jsnews.jschina.com.cn/sy/yw/201801/t20180116_1346958.shtml) · [好友结算](https://jingyan.baidu.com/article/e4d08ffd614d3b0fd2f60d97.html)

| 从低到高 | 依次经过的段位 | 每段星数参考 |
| --- | --- | --- |
| 1–2 | 入门新手、起步熟手 | 1、2 |
| 3–5 | 坚韧黑铁、顽强青铜、傲气白银 | 各 3 |
| 6–9 | 聪慧黄金、巧思白金、睿智黑金、无暇钻石 | 各 5 |
| 10–13 | 智者大师、万卷宗师、博学史诗、智慧传说 | 各 7 |
| 14 | 头脑王者 | 继续累计 |

名称顺序见 1 月攻略，逐段星数取自 4 月整理表。1 月截图能核实初段的 1、2、3 星，部分入场费与 4 月表不同。例如 1 月截图黑铁标 90 金币，4 月表同段列 100。入场费和逐段星数均须注明版本。[1 月排位截图](https://jingyan.baidu.com/article/bad08e1ed7e4d209c9512161.html) · [4 月逐段表](https://www.9game.cn/wzry/2093607.html)

## 界面与布局

| 玩家看到的页面 | 截图所见 |
| --- | --- |
| 首页 | 竖屏蓝底。顶部个人卡显示头像、等级条、金币。下方为大小不同的彩色方块，1 月画面左上大块是排位赛，右上是排行榜，右下接好友对战。 |
| 排位与匹配 | 顶部是赛季和个人进度，段位场纵向排列。每行左侧徽章，中部段位名与金币费用，右侧星位或锁。进入后用地图、头像和同心圆表现寻找对手。 |
| 好友房与入场 | 上方左右各占一位，中间显示等待状态。中部是放弃、邀请按钮，人齐后下方出现开始按钮。入场转场用蓝、红两条斜色带展示头像、地区和等级。 |
| 作答与揭晓 | 双方头像分居顶端两侧，中间是圆形数字倒计时。题干在上半屏，四个等宽答案在中央偏下单列。左右边缘各有一根竖向比分柱，累计分写在柱顶。1 月画面未选项为白色，揭晓正确项变绿。 |
| 末题与结算 | 末题开头大字提示「最后一题」并显示 ×2。结算顶部保留双方分数与连答表现，中间用皇冠和结果徽章突出胜者；中段列金币、经验，底部主按钮继续挑战或再来一局，另有分享战绩。 |
