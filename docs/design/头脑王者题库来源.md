## 选题与许可

42 道授权改编题由荔枝改写为中文，调整了部分题干、选项、单位和解说。选取 OpenTriviaQA 的 19 道题以固定提交及原题所在行为依据；从 Open Trivia DB 精选的 23 道题保留社区题号与投稿者署名。下表所列中文改编按原许可 CC BY-SA 4.0 提供，再分发这些改编时请保留署名、原始链接、修改说明与相同许可。[OpenTriviaQA 许可](https://github.com/uberspot/OpenTriviaQA/blob/dcc1cdf36c2985ed5c849d1f2265c5041ffcdfb9/LICENSE) · [Open Trivia DB API 与许可](https://opentdb.com/api_config.php) · [CC BY-SA 4.0 中文说明](https://creativecommons.org/licenses/by-sa/4.0/deed.zh-hans)

其余 375 道由荔枝独立拟题、编写选项与答案解析。355 道按具体作品、历史、地理、自然或文化资料核对事实；20 道数理题另用给定条件求解。百科多数指向固定修订，也使用了古籍原文、官方机构和作品发行方资料。每道的 source 字段给出其依据。

例如，马拉松赛程取自世界田联，月相的成因据 NASA 讲解，馆藏《蒙娜丽莎》可查卢浮宫作品目录，《黑神话：悟空》的改编来源可查发行商作品介绍。[世界田联](https://worldathletics.org/disciplines/road-running/marathon) · [NASA 月相](https://science.nasa.gov/moon/moon-phases/) · [卢浮宫馆藏](https://collections.louvre.fr/en/ark:/53355/cl010062370) · [PlayStation 作品页](https://www.playstation.com/zh-hans-cn/games/black-myth-wukong/)

## 校验与扩充

仓库根目录运行 `node --test source/test/quiz-bank.test.mjs`，可复查分类数与库存、题号、题干重复、四选一、答案位置、解说、难度、出处与改编署名。新增题目时还需编辑逐题核对答案唯一性、错误选项是否合理、题干是否泄露答案，以及同一知识点是否已收录。

影视、动漫和游戏与文学可能共享作品。首批已为涉及《西游记》与《千与千寻》的跨类题填写 topic，供抽题时使用。
