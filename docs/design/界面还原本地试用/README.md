本页是 2026-11-27 隔离试用的历史记录。新检出可按[试用器源码](../../../source/local-trial/README.md)重建；正式版和当前使用入口见[项目交接](../../项目交接.md)。原机可直接双击[启动荔枝.cmd](../../../source/.local/ui-trial/发行/荔枝界面本地试用-Windows-x64-8b82dc99fb/启动荔枝.cmd)。在另一台 Windows 10/11 x64 电脑上试用，请复制[完整试用包](../../../source/.local/ui-trial/发行/荔枝界面本地试用-Windows-x64-8b82dc99fb.zip)，解压后双击同名启动文件。试用库仅保存在本机。启动后进入青禾的首页，可以发群消息、给好友回帖或赠果，再切换阿青查看结果。结束时在命令窗口按 Ctrl+C。[启动与切换账号](../../../source/local-trial/README.md)
