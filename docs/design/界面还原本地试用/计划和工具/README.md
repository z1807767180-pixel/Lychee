# 计划、聊天时间和工具入口实测

最终本地试用站点使用三个虚构账号。两名成员加入“周末写生组”，第三名保持未加入。下图为实际操作后，从手机尺寸的浏览器窗口截取的画面，每张 788 × 1692 像素。

| 页面 | 实际结果 |
|---|---|
| [我的计划](01-我的计划.png) | 青禾从首页新增“去公园写生”，随后改为“去湖边写生”、12 月 13 日 16:00 和备注“带好画纸和铅笔”。刷新后，首页与个人计划列表都显示新内容。另一名成员查不到该个人计划。 |
| [共同计划](02-共同计划.png) | 从共同计划选择已加入的群，使用原群页面先设置再编辑。另一成员独立登录后，从同一入口读到“湖边写生集合”和 12 月 14 日。未加入者的群列表不含该群，请求群详情和两条成员资料接口均返回 403。 |
| [工具箱](03-工具箱.png) | 日常工具 5 项、一起玩 4 项、AI 工具 2 项，11 个名称各出现一次。头脑王者位于“一起玩”。 |
| [我](04-我.png) | 点头像进入个人资料并看见可编辑字段，返回后点设置可看见“手机网页 V”版本信息。 |

群聊和私聊均用本地夹具准备四条消息，并由页面自行绘制分段。11 月 21 日 23:50 显示日期和时间，23:54 与前条相隔四分钟，沿用原分段。23:59 恰好间隔五分钟，单独显示时间。11 月 22 日 00:01 与前条只差两分钟，跨日后仍显示完整日期和时间。两种会话的实际时间标签顺序全部相同。[实测数据](入口实测.json)

使用最终试用目录 `source/.local/ui-trial/trial-final` 的手机入口 `/mobile/`，以相互独立的浏览器配置和临时 SQLite 执行。新增与修改都通过用户界面完成。历史时间只写入这次新建的测试数据库。本次记录同时保存了实际读取的聊天脚本、主界面脚本与样式的 SHA-256。需要复算时，运行以下命令。[测试脚本](../../../../source/test/social-trial-pages.mjs)

```powershell
node source/test/social-trial-pages.mjs source/.local/ui-trial/trial-final docs/design/界面还原本地试用/计划和工具
```
