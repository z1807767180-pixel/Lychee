# 手机界面本地性能与兼容对照

2026-11-27。最终试用版能在编辑草稿时显示对方发来的消息，同时保留原输入框、焦点、草稿和选区。首次进入显示 100 条历史消息的群，原版中位为 115 毫秒，试用版为 166 毫秒。两版滚动帧间隔基本持平。Android 9 的实际流畅度、系统输入法与手机整机内存仍需在设备上验证。

每列取三轮的中位数，检测 DOM 就绪的间隔约 25 毫秒。首次进入长群的三轮范围，原版为 100–118 毫秒，最终试用版为 163–274 毫秒。冷开包含相同的启动动画。滚动读数来自聊天区逐帧滚动。额外的 5 秒静置窗口内，两版均未记录到新请求。旧设置界面在两版均记录一次本地 `/api/v7/push` 返回 403，发言、收消息、主题读写均能完成。六轮均无脚本异常、外站请求或聊天图片加载错误。

历史试样 `candidate1` 的长群有 529 个界面元素。`candidate2` 减少消息布局容器并共享交互监听，降至 429 个元素。`final` 仅把一份样式从 CRLF 统一为 LF。最终试用目录 `trial-final` 另外修改了聊天与主界面脚本，输入时复用原编辑器并刷新消息列表。上表及三轮实测 JSON 均已用该最终目录重新采样；基线沿用相同环境和夹具的原始三轮结果。

## 状态与输入验证

- 每轮新建两个本地测试账号和两个群，分别通过正常接口写入 150 条与 12 条消息。进入长群时，两版均显示最近 100 条。切换群聊使用窄屏上可见的返回键。
- 在 360 × 780 视口中输入“周末四点树下见。”并缩到 500 像素高。两版都保留原草稿和焦点，输入框可见，发送后另一账号读到原文。另用 Chromium 的输入法调试接口实际把临时拼音 `shu` 确认为“树”。在最终试用版中选中草稿“树”并让另一账号发消息，未退出编辑，聊天列表就出现新内容。随后核对 DOM 输入框对象相同、焦点仍在、草稿完整且选区仍为 0–1。该操作覆盖网页编辑器，厂商键盘候选条与软键盘遮挡仍待设备试用。
- 测试真实切换至第二个标签，确认原页面已隐藏，再冻结、让另一账号发送新消息、解冻并切回原标签。两版均回到原群并收到消息。系统杀进程后的重建属于单独的设备场景。
- 从“我”进入已有主题设置，选“米菲采荔枝”，再回群并重载页面。两版均保存主题值 1；候选的群聊在两次进入时均使用米菲壁纸，同时验证该图片成功解码为 660 × 1,417 像素。原版群聊仍使用原配色。
- 另做 24 次群聊进入，交替切换短群与长群。预热后在第 0、12、24 次进入时主动触发 JS 垃圾回收，再检查同一个长群。原版每次的活动元素均为 324，候选均为 428；浏览器记录的 DOM 节点各自保持 640、764。候选的回收后 JS 堆从 1.85 增到 1.90 MiB。该短时序列未出现每切一次就新增一组页面节点的现象。截图纹理、原生进程和系统内存需要设备测量。

## 环境和复算

基线取自 `cd6a198cceb26d47a5e76d337506591ee18910e6` 的独立 Git 归档，以 npm 离线模式构建了 174 个手机资源。最终站点取自 `source/.local/ui-trial/trial-final`。两者使用各自网站目录、同一台 Windows 10 x64（19045）、Ryzen 5 5600GT、Edge 158.0.4370.33 和相同的 4 倍 CPU 限速。每轮使用新浏览器配置、临时 SQLite 与回环地址。启动前移除网页的 `AbortController` 和 `AbortSignal.timeout`，入园后实读均为 `undefined`。源码的旧浏览器编译目标为 Chromium 69，本次实际执行于 Edge 158。完整网站指纹、三轮读数及重复切群记录可在[三轮实测](三轮实测.json)中复核。

本机有 Windows 虚拟化宿主与 JDK。已核对以前的安卓测试目录、标准 SDK/AVD、Unity 安装、常用工具和缓存目录、USB 测试设备列表。上次专用的 emulator、adb 和 API 28 系统镜像已清理，当前也未识别到安卓测试手机。原有脚本需要已安装的镜像才能运行。此前 [A8.0.1 设备记录](../../../../distribution/android-friends/verified-8.0.1.json) 中的 Android 9 / WebView 69.0.3497.100 属于上一次发行。复测这次界面需要重新准备官方命令行工具、platform-tools、emulator 及 API 28 x86 镜像并创建 AVD，或连接装有待测内核的手机。

最终试用站点有 188 个文件，整站 SHA-256 为 `e1dae33a38f34832538f3c875f06923383434e839efe5c43a70225d7094be988`。与上一过渡目录 `final` 比较，186 个文件相同，改变的是 `social-chat.js` 和 `social-v8.js`。总摘要的计算方法为按 Windows 路径排序，依次对“相对 POSIX 路径的 UTF-8 字节、零分隔符、单文件 SHA-256 二进制摘要”计算 SHA-256。

用 Node.js 24、Edge 和本地网站可运行同一入口。三个参数依次是该版本的源码目录、包含 `mobile/` 的网站目录和结果文件。增加 `--durability` 可复算 24 次换群、回收后读数和组合输入；最终站点另加 `--focus-poll` 可复验编辑中收到新消息。[本地比较脚本](../../../../source/test/mobile-ui-local-compare.mjs)

```powershell
node source/test/mobile-ui-local-compare.mjs source/.local/ui-trial-perf/reference/source source/.local/ui-trial-perf/reference-site source/.local/ui-trial-perf/check-base.json
node source/test/mobile-ui-local-compare.mjs source source/.local/ui-trial/trial-final source/.local/ui-trial-perf/check-final.json --durability --focus-poll
```
