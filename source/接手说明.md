# 荔枝源码接手说明

共享客户端、桌面宿主和手机网页各有版本入口。各端已发布的成品、候选和实测边界见[项目交接](../docs/项目交接.md)。

## 从哪个版本接

| 部位 | 事实源与边界 |
| --- | --- |
| 跨端共享源 | 从本目录开始运行命令。它保留开发工程的原相对路径。`source/web/` 与 `legacy/` 为原业务基线，`source/manifest.json` 校对 151 个输入。 |
| 共享客户端 | `build.py` 从基线合成双入口，通过 `client/` 共用账号、分园、额度、字体和布局。同一 `public-build.json` 记录当前 7.0.0 共享基线的 167 个构建文件的 SHA-256。 |
| Windows W7.0.5 | `desktop/` 提供 WPF/WebView2 宿主、MSI 与验证，`launch/` 管离线首屏。客户端启动后再探测服务；保留置顶等旧功能的原 4.1.7 程序和新客户端独立运行。 |
| 数据与 AI | `server/` 实现本地 SQLite、正式 Turso、旧园兼容和新园隔离，`legacy/` 保留原业务处理器。`upstream/6.3.3/server.mjs` 是原始监听入口，便于比较或离线验证。 |
| 手机 | `static-host/` 提供独立静态网页的同源 API 转发，`android/` 包含 Capacitor 8.6.1 原生工程、输入生成器和构建说明。手机原网址使用 `mobile-web/`，iOS 原生工程在 `ios/`。 |
| 历史及第三方 | 历史清单按工件实测散列区分正式版、候选与别名。安装包、字体、依赖和海龟汤题目的公开归属见本目录 `third-party/README.md` 及上一级历史目录。 |

**公开源有一项有意的配置差异。** 旧三席注册的邀请校验值已从 `legacy/account.mjs` 移出。公开版从管理员的四个服务端环境变量读取，均未设置时旧邀请码注册默认关闭。新版注册、每园邀请码和客户端文件不受影响。`source/manifest.json` 记录 150 个原输入以及该公开模块的新摘要。`server/package-overlay.py` 核对持有人私有归档中原账号模块的完整文件摘要。不要将旧实际校验值或原归档里的环境文件提交进仓库。

## 产品约定

- 公开注册，创建园或用本园的邀请码加入。每个园一枚稳定邀请码，换码后原成员保留。任何已加入成员都可编辑本园名称、简介，查看或更换本园邀请码。个人资料属于本人。仅浏览别人的园 ID 不能查看聊天或图片。
- 工具箱包含提醒事项、约定倒计时、问一问、番茄钟、记账本、照记饮食和交给命运。园中事在荔枝园。「我」保留个人资料、头像、通知和设置，设置显示实际版本。
- 每账号每天合计 20 次问答和 10 次生图，以北京时间零点为界，跨设备和跨园共用。写作与海龟汤主持计入问答，头像和封面计入生图。同一生图作业可查结果，确认没有可取回图片时退还次数。6.4.5 的旧通用错缺少可关联的图片编号，仅能自动归还可从原记录证明在落图前失败的旧请求。
- Windows 新版保持移动应用的全部入口，并适配宽窗侧栏与窄窗。6.4.6 改善工具卡、AI 图片恢复与页内原图。6.4.7 修复窗框拖动，并把番茄钟、记账本、提醒集中到工具箱。原 4.1.7 的发布地址和程序继续独立保留。

## 构建与启动

**共用网页和本地服务。** 已验证的环境为 Node.js 24.18 和 Python 3.12。运行以下命令生成网页并执行使用临时用户和本地供应商的基础回归。

```powershell
python build.py
node --test test/accounts.test.mjs test/ai-quota.test.mjs
$env:LYCHEE_DATA_DIR = Join-Path $PWD '.local/demo'
node server/index.mjs
```

打开 `http://127.0.0.1:10000/mobile/` 或 `http://127.0.0.1:10000/windows/workspace.html`。浏览器运行需要应用仍在线才能读写园数据。启动方式和正式部署的分界见 `server/OPERATIONS.md`。

**Windows EXE 与 MSI。** 使用 Windows x64、Python 3.12、Pillow、.NET Framework 4.x 的 C# 编译器与 WPF 程序集、WebView2 SDK 的 Core/Wpf/Loader。现有 `build.ps1` 从 Visual Studio 的开发组件目录读取三项 SDK 文件。更换构建工具位置时只需调整该脚本的 SDK 取件路径。安装后的普通用户需要系统有 Microsoft Edge WebView2 Runtime。

```powershell
python desktop/release.py dist/win
node desktop/verify-client.mjs dist/win --isolated-host
```

**Windows W7.0.3 候选安装向导。** 候选 MSI 和原件恢复见[候选备份](../archive/windows/7.0.3-RC/README.md)。首次安装推荐 `%LOCALAPPDATA%\LycheeGardenApp`，也可选择普通的专用文件夹。向导根据 Windows 实际登记的位置识别桌面（包括迁到其他盘的桌面），并阻止安装到桌面及其子目录、驱动器根目录或资料库根目录。桌面只创建「荔枝」快捷方式。

旧版若将 `Lychee.exe` 安装到了桌面，或已经手动删除了桌面上的程序，请从「设置 → 应用 → 已安装的应用」卸载 `Lychee Desktop`，再打开 7.0.3 安装包选择专用文件夹。原 7.0.2 MSI 只登记该 EXE、两个快捷方式和两个安装标记。账号、园区资料及 WebView2 用户资料独立保存。原安装位置正常的电脑可以直接覆盖升级。

Windows 图标源 `desktop/lychee-window.png` 取自历史 4.1.7 程序内嵌的透明原图。打包器用同一份多尺寸 ICO 生成 EXE、原生窗口和两个快捷方式的图标，手机继续使用原有图片。正式更新清单尚未建立时，客户端会核对官方仓库身份和公开发行记录；网络失败或结果无法确认时，设置页提供重试。

Windows 独立补丁的版本在 `desktop/build_identity.py` 的 `WINDOWS_VERSION` 维护。发布构建会一起生成版本相符的 EXE、MSI、`stable.json` 和朋友分享 ZIP；共享网页及其他端各用自己的版本清单。

Windows 同卷移动文件会保留原文件权限。分享 MSI 与 ZIP 要在继承输出目录权限的普通暂存目录中生成；验收时用 `Get-Acl` 对比分享文件与原版 `Lychee.msi` 的访问规则，并核对 ZIP 内安装包的 SHA-256。

**7.0 的 Windows 办公小窗。** 在荔枝窗口里按 Ctrl+Q 可以收起主窗口，输入框中的草稿会留在原处，后台仍会收消息。点任务栏的荔枝可回到刚才的页面。拖动窗口四边或四角可调宽高，最小为 320×280 Windows 逻辑像素。宿主在 `desktop/GardenWindow.cs` 处理原生控件；网页输入框和集成标题按钮在 `launch/windows-frame.js`，专属小窗布局在同目录的 `windows-frame.css`。

**7.0 起的 Windows 软件内更新。** 启动时发现新版会提醒，也可以从「设置 → 检查更新」手动检查。便携版更新正在运行的 EXE，保留原目录和自定义文件名。安装版通过当前用户登记的 MSI 组件路径识别并升级。两者继续使用该 Windows 用户原有的 WebView2 资料目录。6.4.7 的使用者需先手动安装或替换一次。

1. 在 `source/` 执行上面的构建和宿主实测。构建器会在产物目录生成配套的 `stable.json`，记录两个包的长度和 SHA-256。若发包前重新签名，先重新嵌入已签名 EXE、签署最终 MSI，再对最终文件执行 `python desktop/update_feed.py --version X.Y.Z --packages dist/win --output dist/win/stable.json`。
2. 获准发布后，先在项目官方仓库的 `windows-vX.Y.Z` Release 上传最终的 `Lychee.exe` 和 `Lychee.msi`，按清单逐一对照已上传文件。随后将同一份 `stable.json` 提交在官方 `main` 分支的 `distribution/windows/stable.json`。客户端固定从该位置读取清单并下载同仓库对应版本的资产。对已经发布的版本保留原件，修订用新版本号。构建命令只生成本地产物。
3. 用 `python test/windows-update-feed.py`、`python test/windows-update-apply.py` 复验下载、包校验、便携替换和故障恢复。以下命令从设置页实测两个真实版本的下载、升级和重开。端到端验收需要已加载用户资料的 Windows 桌面和可正常安装每用户 MSI 的系统。临时测试程序使用单独的产品、组件、快捷方式及 WebView2 资料目录。

```powershell
$qaId = [guid]::NewGuid().ToString()
python desktop/release.py ".local/update-$qaId/old" --qa-version 7.0.0 --qa-instance $qaId
python desktop/release.py ".local/update-$qaId/new" --qa-version 7.0.1 --qa-instance $qaId
node test/windows-update-e2e.mjs ".local/update-$qaId/old" ".local/update-$qaId/new" $qaId
```

`dist/win/Lychee.exe` 与 `dist/win/Lychee.msi` 是构建产物。`dist/win/site` 是带本地启动动画的正式静态页，`dist/win/mobile-static` 是同版手机站发布目录。重编可逐字节复验共享网页，EXE/MSI 会受编译器与安装包生成时间等影响；识别历史正式发行应使用发布工件自身的 SHA-256。安装包是每用户安装，未进行 Authenticode 签名。

如果要启用源目录中的双击本机体验启动器，先将新 EXE 复制为 `client-bin/荔枝.exe`，把 `dist/win/site` 复制为 `release-site`，再运行 `本机体验.cmd`。它会创建独立的本地测试数据。正式朋友版直接双击 Release 里的程序。

**现行手机入口。** 朋友版 APK 从 [Android 工程说明](android/FRIENDS.md)接手；它使用和 iPhone 主屏幕相同的[线上手机网页](mobile-web/README.md)。版本记录分别在 `android/friends-release.json` 和 `mobile-web/releases.json`。

**旧内置 Android 和 iOS。** 在本目录执行 `python android/mobile_assets.py --site dist/win/mobile-static/public --expected-build 6.4.7 --out android/lychee-mobile-assets.zip`，再按 `android/README.md` 的摘要和命令准备 Web 目录。Android 的正式依赖为 Node 22+、JDK 21、Android API 36 和 Build Tools 36.0.0。146 个手机资源已与实际 6.4.7 构建逐件核对。正式 Android 构建及签名验证分别见[构建流程](../.github/workflows/android-release.yml)和[发布流程](../.github/workflows/android-delivery.yml)。网页由 `mobile-web/build.py` 生成，iOS 原生的 Xcode 构建和模拟器测试见[iPhone 工程说明](ios/README.md)。

## 已验证与验收缺口

| 实测 | 结果 |
| --- | --- |
| 公开候选独立检出 | 从 151 个校验输入得到 147 个完整输出，逐项匹配原 6.4.7 构建清单。重新编出 EXE、MSI 并从 MSI 内嵌 CAB 取出程序，确认与本次生成的 EXE 逐字节相同。 |
| 权限、数据与额度 | 独立检出中 11 项账号、隐私与额度回归通过。原项目还用两个隔离账号/园、两个 HTTP 网关、Turso 协议夹具和进程重启测过原园兼容、大图、数据持久化和防重复。 |
| Windows 6.4.7 | 两次在独立 Windows 桌面上验证真实窗口四边/四角拖动，均为 8/8。6.4.6 同条件仅 2/8 有效。另实测 326 像素窄窗、最大化、还原和原图保存。已核对 MSI 从 6.4.6 到 6.4.7 的升级关联和嵌入程序；本轮没有在使用者系统执行现场升级。 |
| 手机与桌面功能 | 在 390×844 和 984×698 两个浏览器视口点开五卡、返回、续计时、跨端修改账单。手机写入 8.90 元，桌面改 9.80 元后读回 980 分。最终静态页在多个隔离会话中验证了账号、换码、原成员保留与新成员入园。 |
| 生图 | 真实 Windows 宿主与本地供应商验证 2048×2048、7,842,417 字节文件分 59 片，返回、重开、下载后字节相同。开户、真实模型各一次和只读相册在正式测试园另行验证；本仓测试默认使用本地模拟供应商。 |
| 仍需设备验收 | Android/iOS 真机、系统级通知送达、进程退出后的定时提醒，以及 iPhone 主屏模式。当前提醒依赖页面或客户端仍在运行。 |

本目录只交付源代码、随包界面资源、构建清单、测试程序与公开说明。私人账号、数据库、会话、AI 密钥、签名私钥、真实上传图片、原始运行日志和受限发布分片由部署方单独保管。备份与代码/数据回退步骤见 `server/OPERATIONS.md`。
