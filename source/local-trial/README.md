# 荔枝界面本地试用

Windows 10 或 11 x64 上，先完整解压压缩包，再双击同一目录里的 **启动荔枝.cmd**。浏览器会打开青禾的小院。保持命令窗口打开，结束时在窗口按 Ctrl+C。再次启动会保留上次的试用记录。

青禾有三位好友，分别是阿青、小满、栗子。荔圈里有「猪圈」与「周末散步团」、私聊和个人约定。荔枝园有一条好友动态和一个问题。青禾的树已有好友送来的两颗荔枝，可以浇水或送出果子。发消息、回复、赠果均写入这台电脑的试用数据。

- 浏览器没有自动出现时，打开 [进入本地试用](http://127.0.0.1:48365/trial.html?start=1)。
- 要从朋友的角度查看收到的消息或赠果，打开[切换试用角色](http://127.0.0.1:48365/trial.html)。登录页也可输入这四个名字，试用口令均为 `Lychee-Trial-8`。
- 试用数据在 `%LOCALAPPDATA%\LycheeLocalUiTrial\profile-v1`。程序只监听本机回环地址。AI 服务、远程数据库与消息推送在这个试用包内关闭。
- 浏览器版呈现本轮共享界面。Windows 原生窗口、安卓系统通知与厂商真机性能按各端单独验收。

## 从项目重建

在 Windows 开发机使用 Python 3.10+、Pillow、已验证的 Windows x64 Node 24.18.0 和同版本 Node 许可。运行 `python <项目>/source/local-trial/package.py --site <手机网页构建目录> --node-license <Node许可>`。网页目录中应含 `mobile/index.html` 及完整移动静态资源。打包器把本地服务、旧业务模块、必要题库、浏览器资源和许可证列入压缩包，并在旁边写出 SHA-256。

运行测试时可传 `启动荔枝.cmd --no-open --data-dir "一个独立测试目录"`，以便使用临时账号库并自行打开浏览器。
