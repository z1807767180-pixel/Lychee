# 荔枝历史版本与归档指纹

共核对 58 份本地文件，按完整 SHA-256 合并为 40 个不同原件。其中 26 个可公开原件，13 个仅公开元数据，1 个待进一步复核。每个原件的实际字节数、完整摘要、版本出处及公开判断均列在 [artifacts.csv](artifacts.csv)。同名但内容不同的文件分别列出。

**原件和历史源码都可以从仓库恢复。** 上述“仅公开元数据”指未清理的整个旧包；其中可公开的逐版源码、美术和设计稿已另行提取。分两种恢复方式：

- **26 个原件。** 从仓库根目录运行 `python history/binary-archive/restore.py --list` 查看编号、相对名及散列。运行 `python history/binary-archive/restore.py --select EDFE0B2C --out restored-windows` 只取正式 6.4.7 Windows ZIP。用多次 `--select` 可按编号、完整相对路径或唯一 SHA-256 前缀选多件；省略 `--select` 还原全部。还原需 Python 3.8+ 与 Git。程序先核对 11 个分片，再验证每个原件的长度和 SHA-256。
- **14 个历史源码与设计快照。** 运行 `python history/source-archive/restore.py --out lychee-historical-sources.zip`，从仓库中的 6 个分片还原完整 ZIP。随后运行 `python lychee-historical-sources.zip --list` 或 `python lychee-historical-sources.zip 6.3.3 restored-6.3.3`。完整 ZIP、每个对象、每版文件和被排除的路径都有校验或说明。各版范围见[历史源码合集](历史源码合集.md)。

**容易混淆的文件名。** 标为“荔枝-6.4.0-工程与本机体验.zip”的现存工程包实际声明 6.4.7。标为 6.4.0、6.4.6 和 6.4.7 的三份 Windows 发行 ZIP，所含 EXE 和 MSI 实际均为 6.4.7。要找 6.4.5 或 6.4.6 的当期产物，应同时对照 PE / MSI 内部版本与最终交付记录。6.4.6 最终 EXE 摘要始于 425ee1dd，对应 MSI 为 0a2b5416；以 6151bca7 开头的是更早的候选 EXE。6.4.7 最终 EXE 摘要始于 635375f9。

**公开范围。** 本目录提供新编清单。原件公开评估沿用项目负责人对荔枝自有随包素材及示例显示昵称的授权。可公开的新版安装包已在本地展开核对文件清单，MSI 的内嵌 EXE 摘要与独立版本核对一致。含环境文件、部署覆盖片段或旧邀请码校验材料的包只登记指纹。含待逐项核实的截图、运行材料，或无法确认原发布来源的包另外标记。第三方依赖继续受各自许可约束。

**核对方法。** 摘要按磁盘原文件逐字节计算，无需运行安装包。CSV 的“本机核对份数”统计同哈希的独立路径，不重复计算 ZIP 内的嵌套文件。历史发布记录来自随原服务保存的 camp.mjs；它只能证明曾记录对应版本。核对范围为留存工作区、相邻交接归档及本机桌面和下载中的荔枝发行材料，不含通用工具链压缩包、线上资料或用户运行数据。
