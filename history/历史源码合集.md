# 按版本还原源码与设计资产

在包含 `history/` 的仓库根目录运行 `python history/source-archive/restore.py --out lychee-historical-sources.zip`，可从 6 个分片还原完整 ZIP。前 5 片各 6 MiB，末片 5,692,525 字节。脚本先逐片核对，再对拼回的整包独立复算固定 SHA-256。若发布页另提供同名整包，也可直接取用。这份合集包含原始移动项目、早期 Windows 试用工程以及有实物留存的 6.4 系列。原始交接 ZIP 的识别摘要在 `artifacts.csv`。合集大小为 **37,149,805 字节**，SHA-256 为 `1d6fdc0085594f326786e0d22969061a7a76ff025aaf1ff0c9c8a1109750aa1c`。

```text
python lychee-historical-sources.zip --list
python lychee-historical-sources.zip 6.3.3 restored-6.3.3
python lychee-historical-sources.zip early-windows-port restored-windows-pilot
```

也可以使用仓库里的独立脚本。例如 `python restore_sources.py --archive lychee-historical-sources.zip 6.2.2 restored-6.2.2`。还原程序检查每项长度和 SHA-256。目标目录必须是新目录，以防覆盖现有的工程。

合集共 14 个快照、2,535 个版本内文件引用，372 份不同内容。七份移动交接 ZIP 各自的发布分片在本机逐项解码对照，所有代码对象均已在对应 `working-source/` 逐字节找齐。合集保留实际源码，省去部署环境、原发布分片和内部交接操作记录。旧账号模块的私有邀请校验值改为服务端环境变量。历史试用工程的现场截图、账号状态和运行日志未收入。各版逐项保留、改写和排除情况可查 ZIP 内 `manifest.json`。

已从发行 ZIP 独立还原 6.3.3 和早期 Windows 移植工程。6.3.3 的 126 个文件中，125 个与原件字节完全相同，含全部 8 张设计稿。其余一个是移出旧邀请校验值的账号模块。13 个服务模块全部通过 Node 语法检查。早期 Windows 移植工程还原 264 个文件。历史快照保留对应年代的功能与资源范围，当前维护入口在 `../source/接手说明.md`。
